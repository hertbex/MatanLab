## Описание работы
В этой лабораторной работе изучается поведение **логистического отображения**, одного из самых известных математических отображений, которое демонстрирует хаотичную динамику. Лабораторная работа сосредоточена на исследовании основных свойств точечных отображений, таких как неподвижные точки, их устойчивость, а также особенности поведения при различных значениях параметра **r**.

В ходе работы с логистическим отображением мы рассмотрим:
- Анализ неподвижных точек и циклов.
- Исследование монотонности последовательности для различных значений параметра **r**.
- Построение бифуркационных диаграмм.
- Применение метода лестницы Ламерея для визуализации сходимости.

## Задания
### Уровень Easy
1. **Математические доказательства**: Обосновать, что для всех значений r ∈ [0; 1], начиная с x₀ ∈ (0; 1), последовательность xn остаётся в пределах (0; 1).
2. **Графики**: Построить графики зависимости xn от xn-1 для нескольких значений параметра r.
3. **Исследования**: Сделать выводы о том, как параметр r влияет на поведение функции зависимости.

### Уровень Normal
1. **Неподвижные точки**: Найти неподвижные точки логистического отображения при различных значениях r.
2. **Монотонность**: Докажите монотонность последовательности {xn} для определённых диапазонов r и постройте графики.
3. **Графическое отображение**: Строить графики с использованием различных значений r, исследуя сходимость.

### Уровень Hard
1. **Циклы**: Изучить циклы порядка m и их влияние на поведение системы.
2. **Лестница Ламерея**: Построить лестницу Ламерея для заданного r и исследовать цикличность.
3. **Динамический хаос**: Изучить влияние хаоса на систему, используя бифуркационные диаграммы и вычисления для различных значений r.

## Основные концепты
- **Логистическое отображение**: Математическое выражение для модели популяции, которое определяется уравнением:
  \[
  x_{n+1} = r \cdot x_n \cdot (1 - x_n)
  \]
  где \( x_n \) — численность популяции на \(n\)-й год, а \(r\) — параметр роста.
- **Бифуркации**: Переходы системы между различными режимами поведения, при которых система может перейти от стабильного состояния к хаотичному.
- **Динамический хаос**: Чувствительность системы к начальным условиям, что проявляется в том, что малые изменения начальных значений могут привести к кардинально различным результатам.
